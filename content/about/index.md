I'm **Robert Love**, a software architect and longtime developer based in Utah.

I've spent much of my career building developer tools, frameworks, and systems intended
to make complicated work repeatable. My interests have moved over the years—from Delphi
components and runtime type information, through application and cloud architecture,
and increasingly into compilers, programming languages, binary formats, code
generation, and systems tooling.

My independent open-source work lives on GitHub as
[**ForgeMechanic**](https://github.com/ForgeMechanic). Most of what I'm working on now
grows out of the same recurring interest: building tools that make difficult technical
work easier to understand, automate, or repeat.

RobertLove.dev is where I write about that work and, more importantly, the ideas behind
it. Some posts document things I've built. Others explore ideas I'm still working
through. I value technical criticism; one of the reasons I write publicly is to find the
assumptions I haven't noticed yet.

## A Note About AI

I use AI extensively in both my software development and my writing.

Because typing has become difficult for me, much of my writing begins with voice
dictation. I use AI to help organize those discussions, clean up transcription, research
questions, challenge my reasoning, and turn what I have said into something readable.

The ideas, arguments, engineering decisions, and opinions expressed here are mine. AI is
part of the toolchain I use to develop and communicate them.

I've written more about that process in
[**How AI Let Me Keep Building**](/posts/how-ai-let-me-keep-building/).

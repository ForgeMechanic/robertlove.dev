Robert Love

I build software tools and systems, with a particular interest in compilers, programming languages, software architecture, binary formats, and the machinery underneath the abstractions developers use every day.

Much of my current work explores a recurring question: how can we turn difficult engineering knowledge into tools that make the next problem easier to solve?

This site is where I write about that work, the experiments behind it, and the ideas that survive contact with implementation.
